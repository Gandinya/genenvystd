# GENENVY Storefront

A responsive, single-page apparel and jersey storefront built with plain HTML, CSS, and JavaScript. No build step or framework is required.

## Preview locally

Open `index.html` in a browser. The page loads its editorial photos from Unsplash and its typefaces from Google Fonts.

## Publish with GitHub Pages

1. Merge this storefront into `main`.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.

## Before publishing

- The four catalog items, descriptions, and displayed prices are sample content. Replace them with confirmed products, prices, and availability.
- The photos are remote editorial images from Unsplash; replace them with GENENVY product photos for a production catalog.
- The cart and custom-order form prepare a message and copy it to the visitor's clipboard. They do not process payment or transmit an order.
- Add the store's real contact/order destination and shipping, exchange, and privacy information before accepting orders.

The site intentionally uses no framework, build tool, API key, or backend.
